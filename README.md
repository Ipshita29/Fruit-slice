# 🍉 Fruit Slice Game

A fun and fast-paced **Fruit Slice Game** built with **React**!  
Slice the fruits 🥝, avoid the chili 🌶️, and get the highest score in 20 seconds!

### ⚙️ Features

- 🕹️ 20-second timed game
- 🍎 Slice apples, bananas, oranges, and watermelons
- 🌶️ Avoid the chili or it's game over!
- 🎯 Score points based on fruit
- 🎉 Smooth animations and minimal UI
